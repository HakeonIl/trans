게임 폴더를 고르세요

게임 실행파일(.exe)이 들어 있는 폴더입니다. 이 단계에서는 읽기만 하고 아무것도 바꾸지 않습니다.

여기를 눌러 폴더 찾기 경로를 알고 있다면 아래 칸에 붙여넣어도 됩니다

분석 결과

Electron 게임입니다. 내용물이 resources/app.asar 한 덩어리에 묶여 있어서 그대로는 번역할 수 없습니다.
풀어놓아도 게임은 그대로 실행됩니다. 되돌리려면 [원래대로]를 누르세요.

알려진 엔진은 아니지만, 읽을 수 있는 텍스트 파일(json·csv·txt 등)이 있습니다. 그대로 진행해도 됩니다 — 대사가 이 파일들에 들어 있으면 잡힙니다. [고급 설정]을 열면 어떤 파일을 읽을지 목록으로 볼 수 있습니다.

🛡️ Ren'Py 게임입니다. 원본 스크립트는 한 글자도 고치지 않습니다. 번역문을 담은 파일 두 개를 game 폴더에 새로 넣는 방식이라, 번역이 틀려도 게임이 죽지 않고 원문이 나올 뿐입니다.

게임에서 번역할 문장을 찾아 표로 만듭니다. 읽기만 하고 아무것도 안 바꿉니다.
뽑고 나면 표에서 [⚡ 자동번역] 으로 채우고, 훑어본 뒤 [게임에 적용] 합니다.

잘 안 될 때

문장이 너무 적게 나올 때. 게임 파일을 읽기만 해서 무엇이 들어 있는지 적은 진단 파일을 만듭니다.
문장이 적게 나오거나, 묶음(.rpa)을 우리가 못 읽었을 때. 무엇이 있고 무엇이 왜 빠졌는지 보여주고, 직접 고르거나 묶음을 풀어 볼 수 있습니다.
번역했는데 게임에서 □□□ 로 나올 때. 글자는 이미 들어갔고 폰트에 한글 모양이 없어서 그렇습니다.
Ren'Py 는 글꼴 파일을 game 폴더에 새로 넣기만 합니다. 원본 글꼴은 그대로 있고, [원래대로]를 누르면 넣은 파일이 지워집니다.
 쓸 글꼴
게임이 아예 안 켜질 수 있습니다. 그러면 [원래대로] 를 누르고 이 칸을 다시 끄면 됩니다. 게임 파일은 백업돼 있습니다.
게임 글꼴에 한글이 구워져 있지 않고 되살릴 원본도 없을 때 쓰는 길입니다. 이미 잘 나오는 글자는 그대로 두고 없는 글자만 채웁니다. 위 [위험] 칸과 달리 원본 글꼴 참조가 없어도 됩니다.

이 문장 어디 있나

게임에서 본 번역 안 된 문장을 붙여넣으세요. 어느 파일 어디에 있고 왜 목록에 없는지 알려줍니다. 제어문자와 줄바꿈은 무시하고 대조하므로 한 줄만 넣어도 되고, 화면에서 본 대로 통째로 넣어도 됩니다.

적용이 안 되었나요?

무엇이 안 되는지 고르시면, 그 경우에 다음에 할 일을 알려드립니다.

자동 번역

기계번역은 초벌입니다. 넣은 뒤 기계 필터로 모아서 훑어보세요.

OpenAI 와 같은 방식으로 말하는 곳이면 다 됩니다. NVIDIA NIM https://integrate.api.nvidia.com/v1 · LM Studio http://localhost:1234/v1 · Ollama http://localhost:11434/v1
로컬에서 돌리는 것이면 위의 API 키는 비워도 됩니다.
한 줄에 원문=번역 하나씩. 번역 뒤에 강제로 적용합니다.
먼저 조금만 돌려서 품질을 보고 늘리세요. 0 = 제한 없음.

일괄 바꾸기

자동번역이 coffee 를 죄다 호빵 으로 옮겨놨을 때 쓰세요. 번역문에서 호빵만 찾아 바꾸면 원래부터 호빵이던 줄까지 바뀝니다. 그래서 원문에 coffee 가 있는 줄로 먼저 좁힙니다.

통으로 옮기기 반자동 번역

문장을 번호 붙여 한 덩이로 뽑아 줍니다. 그대로 번역기 창에 붙여넣고, 나온 결과를 그대로 다시 가져오면 제자리에 돌려놓습니다. 한도도 차단도 없습니다 — 사람이 직접 붙여넣는 것이니까요.

번호는 지우지 마세요 — 제자리를 찾는 유일한 표식입니다.
